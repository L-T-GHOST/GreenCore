# GreenCore AI

> Autonomous thermal intelligence for next-generation green data centers.

A single-page interactive website built with **React + Vite**, featuring:

- 🌆 **Hero** — Parallax cityscape with 2047 timeline slider
- 🧩 **Strategy Hub** — Five interactive tilt-effect pillar cards
- 🖥️ **Digital Twin** — Live server floor simulation with AI toggle
- 📊 **Economic Impact** — Animated charts, CO₂ forest, scalability calculator
- 🌙 **Mission Control** — Night mode automation with AI decision terminal

---

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173)

### 3. Build for production
```bash
npm run build
```

### 4. Preview production build
```bash
npm run preview
```

---

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → Import repo
3. Leave all settings as default (Vite is auto-detected)
4. Click **Deploy** — done ✅
